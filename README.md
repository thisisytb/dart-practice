# Dart Practice

A collection of small console exercises I wrote while learning Dart. Each project lives in its own folder and can be run independently.

## Projects

| Project | Description |
|---|---|
| [age_calculator](./age_calculator) | Calculates a person's age from their birth date and shows how many days are left until the next birthday. |
| [bill_divider](./bill_divider) | Splits a restaurant bill between guests, including a tip percentage entered by the user. |
| [sum_numbers](./sum_numbers) | Reads numbers from the user and calculates their total. |
| [sum_of_digits](./sum_of_digits) | Takes a number and adds up its digits. |
| [unit-converter](./unit-converter) | Converts between units: °C/°F, km/miles and kg/pounds. |

## Requirements

- [Dart SDK](https://dart.dev/get-dart)

## How to Run

Clone the repository and run any project from its folder:

```bash
git clone https://github.com/<your-username>/dart-practice.git
cd dart-practice/unit-converter
dart run
```

If a project is a single file instead of a package, run it directly:

```bash
dart run main.dart
```
